# KindBoard

Внутренняя платформа для сотрудников, где можно отмечать помощь коллег.  

# О проекте

Платформа нацелена на поддержания позитивного настроя среди коллег в компаниях. Это корпоративная «доска поощрений» с элементами социальной сети.

## Стек

- **Backend:** Java + Spring Boot
- **Frontend:** TypeScript + React (Vite)
- **База данных:** PostgreSQL
- **Инфраструктура:** Docker
